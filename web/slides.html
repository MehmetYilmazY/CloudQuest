Teknik öz

Komut doğrulama: regex değil, parser

  • Girdi |, &&, ; ile segmentlere ayrılır.
  • Quote-farkında tokenize edilir; baştaki sudo atılır.
  • Her hedefin bildirimsel expect spec'i ile eşleşir: {cmd, need, anyOf}.
  • Sonuç: flag sırası, fazladan flag ve pipe kullanıcıyı yanlış cevaba düşürmez.
  • Web (parser.js) ve PowerShell (CQ-Match) paritede.
{ "expect": {
    "cmd":  ["chmod"],
    "need": ["+x|755",
              "re:deploy\\.sh$"]
  } }

// hepsi kabul edilir:
chmod +x deploy.sh
sudo chmod 755 ./deploy.sh
ls | chmod +x deploy.sh
